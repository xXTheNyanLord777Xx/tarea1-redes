# Tarea 1 — Proxy HTTP

Proxy HTTP para filtrado de contenido web.

## Cómo ejecutar

1. Asegurarse de tener en la misma carpeta: `proxy.py`, `config.json`, `test.html`, `image.png`.
2. Modificar la variable `IP_VM` en `proxy.py` con la IP de la máquina.
3. Ejecutar: `python3 proxy.py`
4. Probar con curl: `curl http://cc4303.bachmann.cl -x IP_VM:8000`
